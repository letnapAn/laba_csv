# Employee CSV Parser

Приложение для чтения и обработки данных о сотрудниках из CSV-файлов с использованием аннотаций OpenCSV и применением принципов SOLID.

## Описание

Проект демонстрирует современный подход к парсингу CSV-файлов в Java с использованием:
- **OpenCSV** с аннотациями для декларативного маппинга
- **DTO-паттерна** для разделения слоёв приложения
- **Mapper** с кэшированием подразделений
- **Lombok** для уменьшения boilerplate-кода
- **JUnit 5** для тестирования

## Возможности

- Чтение CSV-файлов с автоматическим маппингом полей по имени колонки
- Валидация и конвертация типов данных (String к LocalDate, double)
- Кэширование объектов Division (нет дубликатов подразделений)
- Чёткое разделение ответственности между слоями
- Покрытие unit-тестами критической бизнес-логики

## Архитектурные решения

### DTO и Entity

**CsvEmployee (DTO):**
- Содержит аннотации OpenCSV
- Отвечает за транспорт данных из CSV
- Имеет сеттеры для рефлексии

**Employee (Entity):**
- Чистая доменная модель
- Не зависит от библиотек парсинга
- Реализует бизнес-логику (equals по ID)

### Принцип единственной ответственности (SRP)

- **CsvEmployee** — Маппинг CSV в Java-объект
- **CsvEmployeeReader** — Чтение файла и парсинг
- **EmployeeMapper** — Преобразование DTO в Entity
- **DivisionCache** — Управление уникальностью подразделений
- **FacadeService** — Оркестрация процесса
